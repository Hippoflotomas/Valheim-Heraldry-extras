# Valheim Heraldry Extras

Companion to Valheim Heraldry Mod: extra pieces you can paint with your arms.

Work in progress.

## Planned
- Wall-mounted shield with crossed axes
- Large wall banners, long thin banners, wide tapestries
- More decorative shields

## Requirements
- BepInExPack Valheim, Jötunn
- Valheim Heraldry Mod (optional, but without it nothing gets painted)
- Required on the server and every client, same version
